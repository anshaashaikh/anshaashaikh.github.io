case 01

Credit Risk Analytics Pipeline

PostgreSQL / SQL / Power BI / Python / July 2026

the problem

443K+ raw Lending Club loan records with 151 columns. Hard to query, and nobody could say whether the A to G risk grades held up.

what I built

A normalized PostgreSQL database (4 tables, enforced foreign keys), CTE and window-function analyses, a reusable stored function for borrower risk profiles, and a 3-page Power BI dashboard on live DirectQuery with custom DAX.

how it went

Risk grades rise in step with default rates, and a query that took 273ms now takes 145ms after targeted indexing.

case 03

Stroke Prediction Model

R / October 2025

the problem

Only 4.8% of 5,110 patient records were stroke cases, so a naive model could look accurate and still miss them.

what I built

A Random Forest classifier with ROSE oversampling to handle the imbalance, validated on held-out test data.

how it went

Age, average glucose level and hypertension came out as the top risk factors.
